# Click Adventure

A Foundry VTT module (v14+) that turns any Tile into a point-and-click scene navigation hotspot.

## How It Works

1. Place a Tile on your scene.
2. Open the Tile configuration sheet and go to the **Adventure** tab.
3. Select a target scene from the dropdown.
4. When a player clicks the tile, the world switches to that scene.

## Development

- Foundry VTT v14 minimum
- Uses ApplicationV2 / DocumentSheetV2 architecture
- No dependencies
